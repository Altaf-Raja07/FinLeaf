# Design reference manifest

Every reference below was generated by prompting ChatGPT image generation in an
authenticated browser session, downloaded, and validated (PNG magic number,
plausible dimensions, `IEND` trailer) before being saved here. Dimensions are
recorded in `manifest.json`.

These images are treated as **visual specifications** during implementation:
layout geometry, spacing, typography scale, colour, component sizing, and
hierarchy are matched against them, and each route is screenshot-compared
against its reference before being called visually complete.

## Frame conventions

**Desktop references** are 1586x992. Every app screen uses the same frame:

- Left sidebar, white, hairline right border: FinLeaf wordmark, then exactly
  `Home, Accounts, Send money, Transactions, Pay bills, Save, Loans,
  Sustainability, Learn`, with the current page highlighted in soft green. A
  user chip (`Ravi Kumar` / `View profile`) sits at the bottom.
- No global search bar and no top-right user menu — the app has no global search.
- Content sits right of the sidebar on the warm off-white page background.

**Mobile reference** is 853x1844 (a phone-shaped frame): top app bar with
wordmark and notification bell, stacked single-column cards, and a fixed
five-item bottom tab bar.

## Regenerating a reference

```bash
node scripts/queue-batch.cjs --remaining     # what is missing
node scripts/queue-batch.cjs dashboard        # queue specific pages
node scripts/render-job.cjs start dashboard.png "<prompt>"   # then run via MCP
node scripts/render-job.cjs finish dashboard.png
```

Prompts live in `scripts/prompts.mjs`; the shared visual language they all
prepend is documented in `prompt-prefix.md` and `design-system.md`.

## Known drift, and how it is handled

Early references drifted on the navigation frame: the model invented a top
search bar, a top-right user menu, and different sidebar labels per screen. The
fix was to move the frame definition into the shared `BASE` block in
`scripts/prompts.mjs` and reduce each page prompt to only what is unique about
that page. References generated after that change (`trust-score`,
`dashboard`, and all following screens) share one frame.

Where a generated reference contradicts `design-system.md`, the design system
wins — it is the normative document, and the images are illustrations of it.
